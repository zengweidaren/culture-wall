# Uploads Directory

This directory contains employee photos for the Culture Wall.

## Photo Naming Convention

Photos should be named in the format: YYYYMM-Name.jpg

For example:
- 202603-寮犱笁.jpg
- 202604-鏉庡洓.jpg

## Photo Content

Each photo should include:
- Top section: Employee photo/avatar
- Bottom section: Employee information and achievement description
