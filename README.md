# 智能财务研发部 - 虚拟文化墙

一个美观、科技感十足的单页面文化墙应用。

## 功能特性

- **月份导航**：12个月份任意切换，默认显示当月
- **故事展示**：每月部门故事/事迹展示
- **优秀员工**：头像 + 姓名展示
- **员工管理**：添加、删除、调整顺序
- **图片上传**：支持上传员工头像
- **粒子动效**：科技感十足的粒子背景
- **响应式设计**：适配各种屏幕尺寸

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务器

```bash
npm start
```

访问 http://localhost:3000

## 图片上传说明

### 图片命名规则

将图片放入 `uploads/` 目录，命名格式：

```
YYYYMM-姓名.jpg
```

示例：
- `202603-张三.jpg` - 2026年3月，张三
- `202601-李四.png` - 2026年1月，李四
- `202612-王五.gif` - 2026年12月，王五

### 系统会自动

1. 解析文件名中的年月信息
2. 将员工归类到对应月份
3. 显示员工头像和姓名

## 手动添加员工

1. 点击"添加员工"按钮
2. 输入员工姓名
3. 可选上传头像图片
4. 选择所属月份
5. 确认添加

## 数据存储

员工数据和故事内容存储在浏览器 LocalStorage 中。

如需持久化保存，可以：

1. 将 `localStorage` 数据导出为 JSON
2. 提交到 GitHub 仓库
3. 其他成员访问时导入数据

## 技术栈

- 原生 HTML/CSS/JavaScript
- Canvas 粒子动画
- LocalStorage 数据存储

## 上传到 GitHub Pages

1. 将项目推送到 GitHub 仓库
2. 在仓库 Settings -> Pages 中启用
3. 选择 `main` 分支作为 source
4. 访问 `https://你的用户名.github.io/仓库名`

注意：上传到 GitHub Pages 后，图片需要存放在仓库中或使用图床服务。
